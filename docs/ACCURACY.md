# Accuracy

Generated by `REDACTOR_WRITE_ACCURACY=1 cargo test -p redactor-core --test corpus` (engine 2.1.0). Do not edit by hand.

The corpus lives in `corpus/`. Positive files mark every secret; vendor-shaped tokens are generated at test time from seeded templates, so no real or realistic token is stored in the repository. Negative files contain no secrets at all: code, lockfiles, logs, prose and this project's README.

## Gates

- Balanced (the default) redacts every marked secret, with the expected label where the corpus names one, and finds nothing in the negative files.
- Paranoid also redacts the secrets marked as Paranoid-only (plain words and other values that need a lower bar).
- Scanning any output again changes nothing and finds nothing.
