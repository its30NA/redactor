The parts of the Redactor AppImage that are not libraries
==========================================================

INDEX.txt and the *.copyright files in this folder cover the shared libraries under usr/lib.
Three more parts come from other projects; their licenses follow. Each is the file of the
pinned release that tools/release/appimage-tools.sh checks by sha256.

1. The AppImage runtime: the program at the start of the AppImage file that mounts (or, with
   --appimage-extract-and-run, unpacks) the rest and starts AppRun. From
   https://github.com/AppImage/type2-runtime/releases/tag/20251108 (runtime-x86_64).
   License: the project's LICENSE at that tag, section A below. It names the libraries it links
   in statically and where their licenses are.

2. AppRun.wrapped: the AppImageKit AppRun, which sets up the paths and starts the app. From
   https://github.com/tauri-apps/binary-releases/releases/tag/apprun-old (AppRun-x86_64), a
   mirror of https://github.com/AppImage/AppImageKit/releases/tag/continuous.
   License: AppImageKit's LICENSE, section B below.

3. AppRun (the script that runs the hook, then AppRun.wrapped) and
   apprun-hooks/linuxdeploy-plugin-gtk.sh (sets GTK's theme and data paths). AppRun is written
   by linuxdeploy (https://github.com/linuxdeploy/linuxdeploy, build 07333c6); the hook comes
   from linuxdeploy-plugin-gtk (https://github.com/linuxdeploy/linuxdeploy-plugin-gtk, in the
   copy Tauri's bundler carries). License: MIT, sections C and D below.
