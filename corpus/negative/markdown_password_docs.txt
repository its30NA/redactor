# Account settings

**Password:** the one you chose when you signed up.

**Password**: required, at least 12 characters.

*Password:* see the team vault

- **Username:** your email address
- **Password:** leave empty to keep the current one
- **API Key:** generated on the Settings page

<strong>Password:</strong> must contain a digit.<br>
<b>Password</b>: <em>required</em><br>
<label>Password</label> <input type="password" name="password">

## Parameters

| Name | Type | Required | Description |
|------|------|----------|-------------|
| username | string | yes | The account name |
| password | string | yes | The account password |
| token | string | no | A session token from `/login` |
| api_key | String | no | Your API key |

| Variable | Value |
|---|---|
| DB_USER | app |
| DB_PASSWORD | *(set in the vault)* |
| SECRET_KEY | `<generated>` |

| Setting | Default |
|---|---|
| Password | none |
| Password | required |
